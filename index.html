What's actually running here

  • This is the real 2D model, ported exactly: the same concentric-ring geometry (ringGeometry.m/RegionMap.m — outer wall, inner wall, cavity, in the exact proportions from setup.txt), the same explicit forward-Euler solver with Robin (convective) exterior boundaries and an adiabatic floor (PDESolver.m), the same CFL-based grid-shrink check per experiment (PDEEngine.m), the same Gaussian kiln heat source, the same metric formulas and the same upgraded ranking algorithm — graded constraint violation, feasible-only normalization, Pareto flagging, -999 infeasible sentinel (RankingEngine.m) — all run against the real 58-material database (with the FAMILY field, including the "Quick Select Family" filter) and real NASA POWER Ibadan weather data.
  • Stage 1 Ashby pre-screening is new, and also real: before any 2D simulation runs, pick an Ashby performance-index preset (e.g. "Passive Cooling Outer Wall, 1/α") and a Top-N count, and the Materials tab ranks the entire 58-material pool by that index, checks only the top candidates, and plots them on a log-log chart against the rest — ported from AshbyScreening.m's five index formulas, exactly as the current MATLAB code computes them (ashby.js).
  • A bug this project used to faithfully reproduce has since been fixed upstream, and KelvinK now matches the fix: an earlier MATLAB version's cavityMask selected region ID 2 ("Inner Wall") instead of ID 3 ("Cavity"), so every metric described the wall's temperature, not the room's — a 44°C vs. 308°C difference in one check. The current MATLAB code looks the cavity up by region name instead (tbl.regionID(tbl.RegionName == "Cavity")), and KelvinK does the same.
  • The kiln's heat source has also changed upstream: current main.m uses 5×10⁵ W/m³ for 8 hours when "Kiln" is selected — not the 120,000 W/m³ / 6h from setup.txt, which is now stale documentation.
  • KelvinK's kiln heat source is deliberately re-calibrated, not a straight port of that value. A narrow, intense source (σ=0.5) makes peak_temp and spatial_non_uniform fail together almost every run — the concentration that pushes the center past 1200°C is the same concentration that blows the cavity's spatial spread past 150°C. KelvinK uses a broader, gentler source (σ=5.0, power tuned so the cavity's peak lands mid-band) instead — verified to give 16/27 feasible designs across the full material pool, with physically sensible ranking (insulating walls overshoot, conductive ones vent enough to stay in-band).
